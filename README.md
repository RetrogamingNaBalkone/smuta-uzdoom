# Смута и Raising Dead на UZDoom

Проект ремейков «Смуты» и Raising Dead на движке UZDoom.
Для первой версии приоритет — максимально точный перенос логики оригинальных игр.

## Принципы первой версии

- **Оригиналы — основной ориентир.** Переносим правила, поведение и игровые
  взаимодействия настолько точно, насколько это возможно на UZDoom.
- **Сначала воспроизводим, затем улучшаем.** Изменение баланса, переработка механик
  и другие авторские улучшения не являются целью первой версии. Необходимые
  отступления из-за ограничений движка документируем с причиной и описанием
  отличия от оригинала.
- **Не унифицируем различия без проверки.** Сходные оружие, враги и механики
  могут иметь разные параметры в разных играх. Общую реализацию используем
  там, где она сохраняет поведение каждой игры.
- **Проверяем по оригиналам.** При переносе сопоставляем поведение с исходной
  игрой; неподтверждённые параметры и предположения отмечаем явно.

## План релиза

Предпочтительный формат — единый самостоятельный `.ipk3`, в котором каждая
часть игры представлена отдельным эпизодом.

Это рабочее решение, а не окончательное ограничение архитектуры. При изучении
оригиналов сравниваем ТТХ оружия и врагов: урон, темп атаки, здоровье, скорость
и другие параметры, влияющие на игровой процесс. Если между играми обнаружатся
существенные различия, пересматриваем целесообразность единого `.ipk3`
и способ разделения игр. Решение принимаем по результатам сравнения;
ради общей упаковки не выравниваем баланс оригиналов.

CD-треки «Смуты» поставляются отдельным **опциональным `.pk3`** и не входят
в основной `.ipk3`. Их подключение не должно быть обязательным для запуска
и прохождения игры.

## Локальные материалы

- `originals/` — оригиналы игр для изучения и проверки поведения.
- `uzdoom/` — локальная копия порта UZDoom.

Обе папки исключены из Git через `.gitignore`.
